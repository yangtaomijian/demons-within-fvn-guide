本页按剧情顺序整理 **Public 14.6 主线**的本源之轮窗口，包括锁定教学、双轮、短暂显示和当前版本不可操作的项目。内容会直接涉及分支与结局。

“不干预”指在非锁定窗口出现时不选择本源，继续推进文本。锁定窗口不能靠不干预跳过；少数阶段由界面自动推进，其余才需要完成当前可用操作。需要连续路线与存档安排时，页面会链接到[关键选择与存档](../guide/choices.qmd)。

## 前期：色欲与仓库 {#前期lust-与仓库}

### 康复后的第一晚 {#first-night}

回到卧室后会连续出现四处窗口，完整路线与存档建议见[康复后的第一晚](../guide/choices.qmd#first-night)。

1. **第一次锁定教学：Resnick。** 只能在 Resnick 一侧选择 **色欲**；不能靠继续文本跳过。完成后进入 Edwin 的教学。
2. **第二次锁定教学：Edwin。** 只能在 Edwin 一侧选择 **色欲**。完成后进入双轮。
3. **锁定双轮：Resnick 或 Edwin。** 两边都显示色欲，但选择的是由谁主动带领接下来的互动；只选一侧即可继续。选择 Edwin 的一侧还会在 Tiger Day 的一处回忆中得到不同回应。
4. **收尾窗口：非锁定。** 选择色欲会进入较强烈的收尾；不干预则进入较温和的收尾。两边都结束这一晚，但若之后 Edwin 与 Ludwig 的休假日邀请也都不干预，这里的选择会决定自动进入哪一天。

### 仓库：两次脱身机会 {#warehouse-escape}

Resnick 在废弃仓库被 Gunther 等人围住后，先后有两处非锁定窗口。完整的安全操作和回看建议见[仓库初战](../guide/choices.qmd#warehouse)。

- **第一处：被逼到墙角时。** 目标是 Resnick，实际可选操作为 **色欲**。选择后才会到达第二处；不干预会直接进入被俘链。
- **第二处：尝试从破窗脱身、被 Gunther 抓住时。** 仍以 Resnick 为操作侧，只有先在第一处选择色欲才会出现。再次选择 **色欲** 才进入正常变身链；不干预同样进入被俘链。

### 仓库：正常变身链 {#warehouse-transformation}

只有前两处脱身窗口都选择色欲才会进入这组四次连续操作。四处都是锁定窗口，目标始终是 Resnick，且只有 **色欲** 可执行；顺序完成四次后才回到正常主线。这里没有可等待出来的不干预分支，也不能把四次合并成一次点击。

### 仓库：被俘后的两个结果 {#warehouse-captured}

任一前置脱身窗口不干预都会进入被俘段落。被俘后另有一处非锁定窗口：不干预到达 **Story Ending**；选择 **色欲** 则进入另一条终止链。

后一条链还包含五个连续锁定窗口，只有色欲可执行。依次完成后到达 **Horny Ending**。这些锁定窗口没有各自的自由分支；两种结局都在仓库段终止，不接回正常主线。

## 哨所与休假日 {#watch-house-与休假日}

### 摔跤训练观察 {#watchhouse-wrestling}

Resnick 从房间窗口观察院内训练时，先看 Garret 与 Ludwig，随后才把注意力转向 Edwin 与 Sam。

- **Garret / Ludwig 训练时的第一处窗口：**目标是 Resnick。选择 **色欲** 会让他专注观察这组训练，随后直接前往浴场；不干预才会继续到第二组观察。
- **Edwin / Sam 训练时的第二处窗口：**同样以 Resnick 为目标。选择 **色欲** 会展开对这一组训练的观察；不干预则直接前往浴场。

两处都是可跳过的局部差分，但有先后依赖：第一处选择色欲后不会再出现第二处。两条观察内容之后都汇入浴场；选择只影响当前场景，后面不用为它专门回档。

### 前期 Garret 浴场谈话 {#garret-early-bath}

哨所浴场里，Garret 谈起年轻时认识的灰狼时会出现一处非锁定窗口，目标是 Resnick。

- **不干预：**Garret 在较克制的位置收住往事，谈话随后被打断。
- **色欲：**Resnick 鼓励他继续，谈话与两人的反应更暧昧，之后仍回到同一个打断点。

选择色欲会影响 Bear Day 查资料开场和后来的长官浴场中的少量对话。这些场景的进入条件不受本次选择影响。存档建议见[前期 Garret 浴场谈话](../guide/choices.qmd#garret-early-bath)。

### Edwin / Ludwig 的休假日邀请 {#day-off}

仓库事件后的浴场谈话中，Edwin 的邀请在先，Ludwig 的邀请在后。两处都是非锁定色欲窗口。

- **Edwin 邀请：**选择色欲直接确定 **Tiger Day**，不会再出现 Ludwig 的窗口；不干预才继续到下一处。
- **Ludwig 邀请：**选择色欲确定 **Bear Day**。若也不干预，则由第一晚最后一处选择决定：当时不干预会进入 Tiger Day，当时选择色欲会进入 Bear Day。

两天之后都回到共同主线。要主动比较两边，不必依赖自动回退，按[休假日分流](../guide/choices.qmd#day-off)的两步操作即可。

## Bear Day 与 Tiger Day

### Bear Day：独自查资料 {#bear-library-research}

本场景要求先进入 Ludwig 的休假日。Ludwig 暂时离开图书馆后，Resnick 独自查资料时出现一处非锁定窗口，目标是 Resnick。

- **不干预：**继续查找红眼怪与自身症状的资料。
- **色欲：**注意力转向另一类读物；这会改变当天后面的少量回想，以及长官浴场的一处对话。Resnick 还会把色情读物带回去，后来 Russel 到房间时会从床垫下发现它，并调侃 Resnick。

两边都会等到 Ludwig 回来，不决定是否能进入之后的桌边互动。

### Bear Day：Ludwig 回来后的五处窗口 {#bear-library-ludwig}

两人坐到桌边后，连续互动最多包含五处非锁定色欲窗口。目标与进入关系依次为：

1. **Resnick：**色欲令 Resnick 主动靠近并开启第二处；不干预结束连续互动，回到读书。
2. **Ludwig：**色欲令 Ludwig 接受回应并开启第三处；不干预时 Ludwig 抽回手，连续互动结束。
3. **Resnick：**色欲把互动推进到后半段并开启第四处；不干预转入友好收束。
4. **Ludwig：**色欲令 Ludwig 更主动；不干预保持较克制的回应。两边都会继续到有人接近并出现第五处。
5. **Resnick：**色欲选择继续冒险；不干预则当下停住。两边随后收束这段场景。

前三级任何一次不干预都会提前结束这条连续链；后两级比较的是已经进入后半段后的表现。回看起点与分层存档建议见[Bear Day：图书馆](../guide/choices.qmd#bear-library)。

**捉弄Edwin** 的链接只在前三处任一处不干预后进入的阅读收尾出现。若前三处都选择色欲，便会进入 Ludwig 的后半互动；第四、第五处不干预仍会走该方向的收尾，不会返回捉弄Edwin 链接。捉弄Edwin 与后半互动 Viewer 的查漏关系见[辞书与 Sprite Viewer 查漏](../collectibles/memorium.md#memorium-missables)。

### Tiger Day：较早决定访客 {#tiger-boris-jayden}

本段要求先进入 Edwin 的休假日。Resnick 在酒馆后方与 Boris 对峙时会出现一处非锁定窗口，目标是 Resnick：

- **色欲：**展开与 Boris 的交锋，并把稍后的访客确定为 Boris。
- **不干预：**转去与 Jayden 交谈，稍后的访客为 Jayden。

这处选择决定后来谁来敲门；是否开门和访客是否参与，由房间里的后续窗口决定。完整回看起点见[Tiger Day：Boris / Jayden](../guide/choices.qmd#boris-jayden)。

### Tiger Day：房间里的两处窗口 {#tiger-bedroom}

Resnick 与 Edwin 进入私人房间后，先出现一处锁定双轮：Resnick 与 Edwin 两侧都提供色欲，但目标不同。选择 Resnick 一侧，由 Resnick 主动；选择 Edwin 一侧，由 Edwin 主动。只能选一侧，没有不干预路线；两边之后汇入同一段互动。

稍后还有一处以 Resnick 为目标的非锁定色欲：

- **不干预：**保持当时的互动强度；先前确定的访客仍会敲门，但 Resnick 会隔门让对方离开，不出现访客自己的本源之轮。
- **色欲：**Resnick 把互动推得更强，并在访客敲门后直接开门；只有这样才会到达下一处访客窗口。

较早的双轮只改变 Resnick 与 Edwin 谁主导，不能更换访客；后一个窗口决定是否真正打开访客分支。

### Tiger Day：门口访客 {#tiger-visitor}

这一处只在房间后段选择色欲开门后出现。较早的酒馆后方选择决定显示哪一个版本：

- **Boris 窗口：**目标是 Boris。选择色欲，他接受邀请并加入；不干预时 Boris 拒绝，离开后剧情回到 Resnick 与 Edwin。
- **Jayden 窗口：**目标是 Jayden。选择色欲，他接受邀请并加入；不干预时 Jayden 拒绝，离开后同样回到 Resnick 与 Edwin。

访客是否参与，还会影响后面的少量对话。

## 黑狼伏击与懒惰 {#黑狼伏击与-sloth}

### 黑狼伏击 {#black-wolf}

休假日后的共同主线中，黑狼拔斧并将 Resnick 逼入险境时出现一处非锁定色欲窗口，目标是 Resnick。

- **色欲：**Resnick 得到力量，现场被打断，剧情继续并衔接懒惰能力转折。
- **不干预：**进入“黑狼伏击结局”，在此终止。

Bear Day 与 Tiger Day 之后都能进入这段共同主线。场景识别与提前存档建议见[黑狼伏击与懒惰转折](../guide/choices.qmd#black-wolf)。

### 懒惰碎片战：七个锁定阶段 {#sloth-shard}

从黑狼伏击继续主线后，会进入懒惰碎片相关的能力转折。画面中有 Resnick 与受到懒惰影响的 Ludwig，七次本源之轮的操作目标均为 Resnick。

七个阶段都锁定剧情推进，不过其中三次是自动演出，另外四次才需要手动操作：

1. **懒惰（自动）：**界面自行推进，不需要点击。
2. **懒惰（自动）：**再次自行推进。
3. **色欲（手动）：**选择色欲继续。
4. **色欲（手动）：**再次选择色欲。
5. **色欲（手动）：**第三次手动色欲。
6. **懒惰（自动）：**界面自行推进。
7. **色欲（手动）：**最后选择色欲，完成转折。

锁定状态没有不干预分支。

### Sam 醒来时的圆盘 {#sam-sloth}

能力转折之后，Sam 醒来并追问情况时先显示一处非锁定圆盘。这处圆盘只作展示，不能执行干预；继续文本后会消失。

紧接着才出现真正的锁定操作：目标是 Sam，只有 **懒惰** 可执行。选择后 Sam 再次睡去，剧情进入 Arrival。

## 中后段

### 长官浴场：决定谁留下 {#officer-bath}

Resnick 与 Garret、Brigham 指挥官 同处公共浴场时，先出现一处非锁定懒惰窗口。

- **不干预：**Garret 先离开，Resnick 与 Brigham 留下。
- **懒惰：**Brigham 困倦离开，Resnick 与 Garret 留下。

若留下的是 Garret，之后 Resnick 独自在浴池时还有一处以 Resnick 为目标的非锁定色欲。选择色欲会改变这一小段表现；不干预则保持较克制的版本。两边都进入次日剧情，后面不用为这次选择专门回档。完整场景说明见[长官浴场](../guide/choices.qmd#officer-bath)。

### 长官浴场：Brigham 一侧的 WIP {#brigham-wip}

若第一处不干预而留下 Brigham，稍后会显示色欲，但 **Public 14.6 的正常界面不能执行这项干预**。点击只会显示未来更新提示，不会改变选择结果或开启其他剧情。继续推进文本会沿现有谈话进入次日。

### 真心话大冒险：四轮提问 {#truth-or-dare}

林中休整时，Edwin、Ludwig、Resnick 与 Sam 依次主持一轮。四处都是非锁定色欲窗口，按顺序都会出现，不因前一轮的选择被跳过。

1. **Edwin 的回合，目标是 Edwin。** 不干预时，他问 Ludwig 身材方面的问题；色欲将问题改为 Ludwig 过去更大胆的经历。两边都轮到 Ludwig。
2. **Ludwig 的回合，目标是 Ludwig。** 不干预时，他让 Resnick 做足部按摩一类的动作；色欲将要求改为让 Resnick 在余下游戏中保持更少衣着。这次选择色欲还会影响之后的 Ludwig 按摩。
3. **Resnick 的回合，目标是 Resnick。** 不干预时，他给 Sam 一个轻松玩笑式挑战；色欲将挑战改为 Sam 与 Edwin 的亲密互动。这个结果会在之后的 Edwin 河边场景中得到简短回响。
4. **Sam 的回合，目标是 Sam。** 不干预时，Sam 询问 Edwin 的资金来源，正文出现 **崇高之捐赠** 高亮链接；条目仍需主动点击。色欲会让 Sam 改问 Edwin 更私人的经历，因此不显示该链接。

若目标是补条目，只需在第四轮前留档并选择不干预；若要比较四轮全部主要文本，需从这一局真心话大冒险开始前分别回看。

### Edwin 河边 {#edwin-river}

这段只会在较早进入 Edwin 的休假日后出现。两人坐在河中靠近时，先出现以 Edwin 为目标的非锁定色欲。

- **第一处不干预：**保持亲近但克制的依偎与耳后轻挠，随后结束河边夜晚；不会出现第二处。
- **第一处选择色欲：**两人的互动转得更直接，并在稍后出现第二处 Edwin 窗口。
- **第二处不干预：**继续已经开始的亲密互动，以较克制的方式收束。
- **第二处选择色欲：**互动进一步升级，再进入同一夜晚的结尾。

第一处是第二处的进入条件。真心话大冒险中 Resnick 的较早色欲会改变这里一小段回想文字，但不是进入河边或第一处窗口的必要条件。

### Ludwig 按摩 {#ludwig-massage}

这段只会在较早进入 Ludwig 的休假日后出现。Ludwig 在帐篷里替 Resnick 按摩时，通常会先出现以 Ludwig 为目标的非锁定色欲。

- **第一处不干预：**保持普通按摩并转到足部按摩，随后结束；不会出现第二处。
- **第一处选择色欲：**按摩转入更亲密的方向，并开启第二处。
- **第二处不干预：**Ludwig 继续以手部动作为主并完成这段互动。
- **第二处选择色欲：**Ludwig 改用更主动的回应，之后仍进入同一晚的收束。

若真心话大冒险的 Ludwig 回合选择过色欲，按摩时会直接进入第一处色欲的结果，不再让你选择第一处本源之轮；随后仍会出现第二处。

### 市场后的 Gunther 二次战 {#gunther-rematch}

Resnick 在旧城区再次与 Gunther 交手时出现一处非锁定三向窗口，目标是 Gunther。

- **不干预：**Gunther 按普通交战过程逐渐体力不支。
- **色欲：**Gunther 更容易分心、动作躁动，衣着表现随之改变。
- **懒惰：**Gunther 明显迟缓、疲惫，呈现另一组衣着状态。

三边都会继续到黑狼出现；Gunther 的衣着和部分反应会随本次选择延续到下一段。存档建议见[Gunther 二次战](../guide/choices.qmd#gunther-rematch)。

### Garret 办公室喝酒 {#garret-office}

Garret 解开衬衫时先出现一处以 Resnick 为目标的非锁定色欲。选择后 Resnick 会尝试靠近，但 Garret 明确拒绝，随后回到喝酒谈话；不干预则直接进入同一谈话。

Garret 提起过去认识的年轻狼后，出现主要的非锁定三向窗口：

- **不干预：**Garret 继续谈自己的过去，随后结束夜谈。
- **色欲：**谈话转向吸引与犹豫，Garret 仍然收住并结束会面。
- **懒惰：**Garret 困倦，开启后续连续窗口。

选择懒惰后，Garret 再次让 Resnick 离开时出现第二处窗口，此时只有 **懒惰** 有结果：不干预会结束这一晚；懒惰会让他睡去并顺序展示前两种状态。之后出现最后一处非锁定色欲，不干预进入另一段观察文字并离开，选择色欲则显示第三种状态后结束。

想把三种画面都看完，按懒惰 → 懒惰 → 色欲走即可。若还想看不干预与第一次色欲的完整对话，再从更早的存档回看，详见[Garret 办公室喝酒](../guide/choices.qmd#garret-office)。
